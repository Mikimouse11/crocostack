# SEO

- Every rename, merge, or deletion of a product or category gets a 301 redirect to the closest live page. Never redirect to the home page.
- Write handles in lowercase with hyphens, using the product-type words. No IDs, dates, or stop words. Set a handle once. Changing it needs a redirect.
- Each product has one URL. Collection paths to the same product carry a canonical that points to that URL.
- Category pages rank for broad searches, so they matter more than product pages. Give each a unique short intro and a meta title built on the category's search phrase.
- Keep a meta title to about 60 characters, with the search phrase first. Put the store name last or leave it out.
- Keep a meta description to about 155 characters. It doesn't affect Google ranking (Google usually rewrites descriptions), but can be shown when page is shared to social media or in a message.
- Variants don't get their own indexable pages unless shoppers search for them separately.
- Keep an out-of-stock page live if the product will come back. Redirect it if the product is gone for good. Never return a 404 on a page that gets traffic.
- Structured data (price, availability, brand, GTIN, reviews) comes from catalog fields. Wrong catalog data produces wrong search results.
