# Product descriptions

- These rules apply to long form product description texts and are separate from "short description" or "meta description" rules.
- Each store and product category has a different style of description text. But usually a description is a free form text and answers the questions that stop a purchase: what it is, who it is for, what it is made of, how it fits or sizes, what is included, and how to care for it.
- Open with one sentence about what the product does for the buyer. 
- Be specific instead of using adjectives: "fits a 16-inch laptop", not "spacious".
- The original copy from the manufacturer is usually a good starting place, but everybody else is also using it. If possible, add a personal touch.
- Match length to price and complexity. A cheap basic needs 50 words. An expensive or technical product earns 300.
- Don't repeat store-wide shipping and returns policies or other info not unique to the product.
- Never invent facts. Flag missing information instead.
- Specs table values belong in product attributes, not description text. However, if no attribute system is available, put it in the description as a fallback.
